Junior Backend Engineer

at Lumen Ledger

About Lumen Ledger

Lumen Ledger builds double-entry accounting infrastructure for small online businesses: an API that turns payment events into a clean general ledger.

What you'll do

  • Build and maintain Node.js and TypeScript services behind our ledger API
  • Write PostgreSQL migrations and queries that stay correct under concurrency
  • Own small features end to end, from design note to production

What we're looking for

  • 1+ years building backend services in TypeScript or Python
  • Comfort with SQL and relational modelling
  • Nice to have: Docker, AWS, an interest in accounting systems
