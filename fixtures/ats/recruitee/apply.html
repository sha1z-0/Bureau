Junior Web Developer

Tulip & Tern · Utrecht, Netherlands · Remote within EMEA · Full-time

Tulip & Tern is a 30-person studio building booking and storefront software for independent florists in the Netherlands and Belgium. You'll join a team of four web developers working on our customer storefronts (Next.js) and the Elixir/Phoenix API behind them.

About the role

You'll build features for florists' storefronts and the dashboard they use to manage bouquets, delivery slots and orders.

What you'll do

  • Build React components and pages in our Next.js storefront
  • Write and review small API changes in Elixir with a senior developer
  • Fix bugs reported by florists, and talk to them when it helps

What we're looking for

  • 1-2 years of professional web development (internships count)
  • Good JavaScript/TypeScript and React
  • Curiosity about the backend; no Elixir experience needed

What we offer

  • Fully remote within UTC-1 to UTC+5
  • EUR 1,500 yearly learning budget
  • A team that writes things down
